Privacy

Last updated: April 2026

The short version

SALI collects nothing about you. No cookies. No analytics. No tracking pixels. Your salary inputs never leave your device — the calculator runs entirely in your browser. The only network requests the page makes are for live market data (Bitcoin price, exchange rates, $STRC yield), and those requests carry no identifying information.

External services contacted

When you load the calculator, the page makes the following anonymous requests to third-party services:

Coinbase Public API
Live Bitcoin spot price (USD). Anonymous HTTP request — no account, no key, no identifying data sent.
api.coinbase.com/v2/prices/BTC-USD/spot
Frankfurter (European Central Bank)
Live EUR and MXN exchange rates for multi-currency salary input. Anonymous request.
api.frankfurter.app/latest
Yahoo Finance
Live $STRC (Nasdaq) stock price, used to compute the current dividend yield for the "Salary Under $STRC" feature. Anonymous request with a 2-second timeout. If the request fails or is blocked (common due to CORS), the calculator silently falls back to the publicly stated 11.5% rate.
query1.finance.yahoo.com/v8/finance/chart/STRC
jsDelivr CDN
Chart.js library file for rendering the SALI chart. Standard CDN request — your IP is visible to jsDelivr as with any CDN.
cdn.jsdelivr.net/npm/chart.js
YouTube (nocookie mode)
Embedded podcast video on the Podcast page, loaded via youtube-nocookie.com. In nocookie mode, YouTube does not set tracking cookies unless you interact with the player.
www.youtube-nocookie.com

What is not collected

  • Your salary figures — computed and displayed in-browser only, never transmitted anywhere
  • Your name, email address, or any personal identifier
  • Session cookies or persistent cookies of any kind
  • Browser fingerprint, screen size, or behavioral analytics
  • Location data

URL parameters

The calculator encodes your inputs (salary, start year, forecast settings, STRC allocation) as URL query parameters so you can bookmark or share a specific setup. These parameters exist only in the URL string in your browser — no server reads or logs them. Shared links contain only your calculator settings, never data that could identify you personally.

Data storage

Nothing is stored on any server. The calculator has no backend, no database, and no user accounts. All computation happens locally in your browser.

Hosting

The site is served as static files. The hosting provider may collect standard server access logs (IP address, timestamp, path) as part of normal web hosting operations. These logs are not used for analytics or advertising.

Third-party links

External links (to strategy.com, Nasdaq listings, etc.) are provided for reference. SALI has no control over the privacy practices of those sites.

Changes

If material changes are made to this policy, the "Last updated" date above will change. The site has no mechanism to notify you directly — check this page periodically if you want to stay current.
