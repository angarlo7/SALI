Privacy

Last updated: July 2026

The short version

SALI does not collect your salary, name, email, or personal account data. The calculator runs in your browser. SALI uses Cloudflare Web Analytics for privacy-friendly traffic counts; it does not use cookies, advertising trackers, or cross-site user profiles.

External services contacted

When you load the calculator, the page makes the following anonymous requests to third-party services:

Coinbase Public API
Live Bitcoin spot price (USD). Anonymous HTTP request - no account, no key, no identifying data sent.
api.coinbase.com/v2/prices/BTC-USD/spot
Frankfurter (European Central Bank)
Live EUR and MXN exchange rates for multi-currency salary input. Anonymous request.
api.frankfurter.app/latest
jsDelivr CDN
Chart.js library file for rendering the SALI chart. Standard CDN request - your IP is visible to jsDelivr as with any CDN.
cdn.jsdelivr.net/npm/chart.js
YouTube (nocookie mode)
Embedded podcast video on the Podcast page, loaded via youtube-nocookie.com. In nocookie mode, YouTube does not set tracking cookies unless you interact with the player.
www.youtube-nocookie.com
Cloudflare Web Analytics
Privacy-friendly traffic analytics: page views, visits, referrers, country-level location, device/browser basics, and performance metrics. Cloudflare Web Analytics does not use cookies and does not track individual visitors across sites.
static.cloudflareinsights.com/beacon.min.js

What is not collected

  • Your salary figures as account data or user records - SALI has no backend, no database, and no user accounts
  • Your name, email address, or any personal identifier
  • Session cookies or persistent cookies of any kind
  • Advertising identifiers, behavioral ad profiles, or cross-site tracking cookies
  • Location data

URL parameters

The calculator encodes your inputs (salary, start year, forecast settings) as URL query parameters so you can bookmark or share a specific setup. If you share or visit a URL that contains salary settings, those settings are part of the URL and may be visible to the recipient, browser history, hosting logs, and aggregate analytics tools. The in-app "Post on X" grade link is grade-only and does not include your salary.

Data storage

Nothing is stored on any server. The calculator has no backend, no database, and no user accounts. All computation happens locally in your browser.

Hosting

The site is served as static files. The hosting provider may collect standard server access logs (IP address, timestamp, path) as part of normal web hosting operations. SALI also uses Cloudflare Web Analytics to understand aggregate traffic and page performance without cookies or advertising trackers.

Third-party links

External links are provided for reference. SALI has no control over the privacy practices of those sites.

Changes

If material changes are made to this policy, the "Last updated" date above will change. The site has no mechanism to notify you directly - check this page periodically if you want to stay current.
