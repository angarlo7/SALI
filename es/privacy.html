Privacidad

Última actualización: mayo de 2026

La versión corta

SALI no recopila tu salario, nombre, correo electrónico ni datos de cuenta personal. La calculadora funciona en tu navegador. SALI utiliza Cloudflare Web Analytics para conteos de tráfico amigables con la privacidad; no usa cookies, rastreadores publicitarios ni perfiles de usuario entre sitios.

Servicios externos contactados

Cuando cargas la calculadora, la página realiza las siguientes solicitudes anónimas a servicios de terceros:

API Pública de Coinbase
Precio spot en vivo de Bitcoin (USD). Solicitud HTTP anónima — sin cuenta, sin clave, sin datos identificables enviados.
api.coinbase.com/v2/prices/BTC-USD/spot
Frankfurter (Banco Central Europeo)
Tasas de cambio en vivo de EUR y MXN para la entrada de salario en múltiples monedas. Solicitud anónima.
api.frankfurter.app/latest
Yahoo Finance
Precio en vivo de $STRC (Nasdaq), usado para calcular el rendimiento de dividendo actual para la función "Salario Bajo $STRC". Solicitud anónima con tiempo de espera de 2 segundos. Si la solicitud falla o es bloqueada (común por CORS), la calculadora silenciosamente usa la tasa declarada públicamente del 11.5%.
query1.finance.yahoo.com/v8/finance/chart/STRC
jsDelivr CDN
Archivo de la librería Chart.js para renderizar el gráfico SALI. Solicitud estándar de CDN — tu IP es visible para jsDelivr como con cualquier CDN.
cdn.jsdelivr.net/npm/chart.js
YouTube (modo sin cookies)
Video del podcast incrustado en la página de Podcast, cargado vía youtube-nocookie.com. En modo sin cookies, YouTube no establece cookies de seguimiento a menos que interactúes con el reproductor.
www.youtube-nocookie.com
Cloudflare Web Analytics
Análisis de tráfico amigable con la privacidad: vistas de página, visitas, referentes, ubicación a nivel de país, básicos de dispositivo/navegador y métricas de rendimiento. Cloudflare Web Analytics no usa cookies y no rastrea visitantes individuales entre sitios.
static.cloudflareinsights.com/beacon.min.js

Lo que no se recopila

  • Tus cifras salariales como datos de cuenta o registros de usuario — SALI no tiene backend, base de datos ni cuentas de usuario
  • Tu nombre, dirección de correo electrónico ni ningún identificador personal
  • Cookies de sesión ni cookies persistentes de ningún tipo
  • Identificadores publicitarios, perfiles de anuncios conductuales ni cookies de seguimiento entre sitios
  • Datos de ubicación

Parámetros de URL

La calculadora codifica tus entradas (salario, año de inicio, configuración de proyección, asignación STRC) como parámetros de consulta de URL para que puedas guardar como favorito o compartir una configuración específica. Si compartes o visitas una URL que contiene configuraciones de salario, esas configuraciones son parte de la URL y pueden ser visibles para el destinatario, el historial del navegador, los registros de hosting y las herramientas de análisis agregado. El enlace de calificación "Publicar en X" de la aplicación es solo de calificación y no incluye tu salario.

Almacenamiento de datos

Nada se almacena en ningún servidor. La calculadora no tiene backend, base de datos ni cuentas de usuario. Todo el cálculo ocurre localmente en tu navegador.

Hosting

El sitio se sirve como archivos estáticos. El proveedor de hosting puede recopilar registros de acceso estándar del servidor (dirección IP, timestamp, ruta) como parte de las operaciones normales de hosting web. SALI también usa Cloudflare Web Analytics para entender el tráfico agregado y el rendimiento de la página sin cookies ni rastreadores publicitarios.

Enlaces de terceros

Los enlaces externos (a strategy.com, listados de Nasdaq, etc.) se proporcionan como referencia. SALI no tiene control sobre las prácticas de privacidad de esos sitios.

Cambios

Si se realizan cambios materiales a esta política, la fecha de "Última actualización" arriba cambiará. El sitio no tiene mecanismo para notificarte directamente — revisa esta página periódicamente si quieres mantenerte al tanto.
